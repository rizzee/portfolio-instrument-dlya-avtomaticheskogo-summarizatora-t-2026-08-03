# Text Summarizer

Консольное приложение для автоматического сокращения длинных статей до кратких тезисов. Инструмент помогает быстро извлекать суть из больших объемов текста, используя методы NLP.

### Запуск

Для начала работы установите зависимости:
```bash
pip install -r requirements.txt
```

Запустите приложение через терминал:
```bash
python main.py --input article.txt --ratio 0.3
```

### Пример

**Входной текст:**
> "Искусственный интеллект меняет мир. Он внедряется в медицину, транспорт и образование. Многие специалисты считают, что это приведет к автоматизации большинства процессов. Однако важно соблюдать этические нормы."

**Результат (summary):**
> - Искусственный интеллект меняет мир.
> - Он внедряется в медицину, транспорт и образование.
> - Важно соблюдать этические нормы.
